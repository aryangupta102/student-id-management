# student-id-management
The Student ID Management System is a simple Python-based project designed to manage and organize student identification records efficiently. The project provides a basic system for storing, viewing, searching, updating, and managing student details.
# Student ID Management System

A simple **Student ID Management System** developed using basic Python.
This project allows users to manage student records, attendance, marks, fees, and student ID cards through a menu-driven program.

## Features

* Add a new student
* Display all student records
* Search for a student using Student ID
* Update student information
* Delete student records
* Display a student ID card
* Update attendance percentage
* Enter student marks
* Calculate and display grades
* Update fee status
* Generate a complete student report
* Simple and easy-to-use menu-driven interface

## Technologies Used

* **Python**
* Lists
* Dictionaries
* Functions
* Loops
* Conditional statements
* User input

No external libraries are required.

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or any Python editor.
3. Open the Python file.
4. Run the program using:

```bash
python main.py
```

5. Select an option from the menu and follow the instructions displayed on the screen.

## How It Works

The program stores student information in a Python list. Each student is represented using a dictionary containing details such as:

* Student ID
* Name
* Age
* Gender
* Course
* Branch
* Year
* Phone Number
* Email
* Attendance
* Marks
* Fee Status

The user can access different functions through the main menu to manage these records.

## Grading System

The program assigns grades according to the marks percentage:

|    Marks | Grade |
| -------: | :---: |
|   90–100 |   A+  |
|    80–89 |   A   |
|    70–79 |   B   |
|    60–69 |   C   |
|    50–59 |   D   |
|    40–49 |   E   |
| Below 40 |   F   |
